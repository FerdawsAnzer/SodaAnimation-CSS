# 🎨 Soda Can Animation — The Power of CSS ✨

This is a fun and interactive soda can animation built using **only HTML and CSS** — no JavaScript!

## 🧪 Features

- Smooth transition on hover
- Cover slides away to reveal a different soda color
- Layered design using CSS variables and positioning
- Creative use of:
  - `mask-image`
  - `background-blend-mode`
  - CSS transitions
  - Flexbox layout


## 🚀 Technologies Used

- HTML5
- CSS3
- Custom properties (CSS variables)
- Responsive layout techniques
